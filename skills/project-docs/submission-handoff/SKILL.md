# 제출 문서 넘기기

## 왜 있는가

2026-10-01 사용자가 정했다. "앞으로는 내용 초안과 양식을 그대로 복사한 문서를 주시면 제가 정리해서 작성할게요."
담당 교수는 내용을 모르고 낸 뒤 질문에 답하지 못하는 학생 때문에 AI 로 만든 제출물을 감점한다.
사용자는 이해용 보고서로 내용을 익히고, 최종 문서는 자기가 쓴다.

그래서 **최종 제출본은 사람만 쓴다.** 에이전트가 생성기를 돌려 최종본을 덮거나, 복사하다가 고치는 일이 없어야 한다.
그날까지 제출물 대부분을 에이전트 생성기가 썼다. 검토 도구로 보니 5주 동안 낸 문서 24개 중 15개가 "AI 판" 이었다.

## 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `scripts/handoff.py check <경로…>` | 쓰려는 경로가 최종 제출본이면 🔴 와 종료 코드 2. 작성용 폴더 안의 초안 · 사본은 🟢 |
| `scripts/handoff.py give --form --dest --name [--draft]` | 양식을 `<제출 폴더>/작성용/<최종 파일명>` 으로 바이트 그대로 복사하고 해시를 맞춰 본다. 기록을 `작성용/전달기록.jsonl` 에 남긴다 |
| `scripts/handoff.py verify --dest` | 넘긴 사본이 아직 빈 양식인지, 바뀌었는지, 초안이 넘긴 그대로인지 |

처음 한 번 `setup.ps1`(윈도) 또는 `setup.sh` 를 돌린다. 파이썬 버전만 본다.

## 절차 — 제출 문서 요청을 받으면

1. **최종본인지 먼저 가린다.** 만들 파일 경로마다 `handoff.py check` 를 돌린다. 🔴 면 그 파일에 쓰지 않는다.
   생성기(`build_*.py` 등)가 최종본 이름으로 저장하게 되어 있으면 돌리지 않는다. 생성기 출력 경로를 `작성용/` 아래로 바꾸지도 않는다 — 생성기가 만든 문서는 사람이 쓴 문서가 아니다.
2. **양식을 찾는다.** 학교 · 회사가 배포한 양식 파일이다. 확장자가 곧 최종본 확장자다(.hwp 양식이면 최종본도 .hwp).
3. **내용 초안을 md 로 쓴다.** 양식의 칸 순서대로 소제목을 달고, 칸마다 들어갈 내용을 적는다.
   초안은 사람이 읽고 자기 말로 옮겨 쓸 재료다. 양식에 붙여 넣을 완성 문장이 아니라 **사실 · 결정 · 수치 · 근거 위치**를 적는다.
   초안 파일은 `<제출 폴더>/작성용/<짧은 이름>_초안.md` 에 둔다.
4. **양식 사본을 넘긴다.** `handoff.py give --form <양식> --dest <제출 폴더> --name <최종 파일명> --draft <초안>`.
   사본은 양식과 해시가 같아야 한다(스크립트가 확인한다). 사본을 열어 글을 넣지 않는다.
5. **사람에게 알린다.** 사본 경로, 초안 경로, 최종본으로 옮길 자리(`<제출 폴더>/<최종 파일명>`)를 알린다. 날짜 · 회의 시각처럼 사람이 정할 칸은 초안에 "사용자 확인" 으로 비워 둔다.
6. **넘긴 뒤에는 그 파일을 열지 않는다.** 확인이 필요하면 `handoff.py verify` 와 `ai-trace-audit` 로 읽기만 한다.

## 하지 않는 것

- 최종 제출본 · 작성용 사본에 글을 넣거나, 서식 · 칸 크기를 바꾸거나, 변환(hwpx → hwp 등)하지 않는다. 변환도 사람이 한글 · Word 로 저장해서 한다.
- 파일 정보(작성자 · 저장 시각 · 프로그램 이름)를 바꾸거나 지우지 않는다. AI 흔적을 감추는 일을 하지 않는다. 이 스킬은 사람이 쓰는 흐름을 지키는 도구다.
- 사람이 쓰는 중인 파일을 덮지 않는다. `give` 는 사본이 이미 있으면 멈춘다.

## 함정

1. 생성기는 최종본 이름을 코드 안에 갖고 있다(`OUT = …_5주차_회의록.hwpx`). 무심코 돌리면 사람이 고친 판을 덮는다. 2026-10-01 에 회의록 · 시나리오 · 설계서 생성기가 모두 그랬다.
2. 렌더 확인용으로 한글 · Word 를 COM 으로 열면 저장하지 않아도 잠금 파일이 생긴다. 사람이 쓰는 중에는 열지 않는다.
3. `shutil.copy2` 는 시각까지 옮긴다. 사본은 `copyfile` 로 내용만 복사한다 — 넘긴 시각이 곧 사본의 시각이 되어 검토가 쉽다.

## 관계

- 검토: [[ai-trace-audit]] — 제출 폴더에서 에이전트가 쓰거나 고친 파일을 찾는다.
- 양식 확장자 규칙과 날짜 확인은 프로젝트 규칙을 따른다.
