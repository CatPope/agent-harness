- 뜻: 버튼·라벨·안내처럼 화면에 들어가는 짧은 글. 입력칸 아래 설명은 도움말 텍스트.
- 전하는 말: "도움말 텍스트를 걷어 내고 상태는 배지로 보여 주세요."

### 가로 배치 헤더 (horizontal header) · 리딩 아이콘 (leading icon) · 미디어 오브젝트 (media object) · 리딩 아이콘 직접 씀 (09-28)
- 날짜: 2026-09-28 · 화면: 경고 창
- 하신 말: "경고창에서 경고 아이콘을 왼쪽에, 대화 상자 제목을 오른쪽에 둬서 한 줄로 만들어야 해요."
- 상황: 레퍼런스처럼 아이콘이 제목 위에 있던 것(세로 배치, stacked)을 제목 앞으로 옮겼다. 바로 다음 요청에서 사용자가 "리딩 아이콘의 크기를…" 이라고 용어를 직접 썼다.
- 뜻: 아이콘을 글 앞에 나란히 두는 헤더. 글 앞의 아이콘이 리딩, 뒤가 트레일링. 아이콘 + 글 묶음 배치 전체를 미디어 오브젝트라 부른다.
- 전하는 말: "경고 창 헤더를 가로 배치로, 경고 아이콘은 리딩 아이콘으로."
- 이어서: 세로 가운데 정렬

### 정렬선 (keyline) · 근접성 (proximity) · 시각적 그룹 (visual grouping)

- 날짜: 2026-09-28 · 화면: 파일 전달
- 하신 말: "파일 전달 페이지의 폼 카드와 전달 상태 표를 자료 페이지의 탭 형식으로 바꾸는 게 좋아 보여요."
- 상황: [보내기 | 전달 상태 5] 탭으로 나눴다. 현재 탭은 밑줄로 표시.
- 뜻: 한 화면 안의 내용을 이름표로 갈라 하나씩 보여 준다.
- 전하는 말: "보내기와 전달 상태를 밑줄 탭으로 나눠 주세요."
- 이어서: 세그먼트 컨트롤 (segmented control)
- 다시: 2026-09-29 · 모바일 전달(M-04). "보내기 전달 상태 넣기". 웹에만 있던 탭을 모바일에도 넣고, 두 탭을 같은 폭으로 나눴다

### 그리드 열 수 (column count) · 스택 목록 (stacked list)
- 날짜: 2026-09-28 · 화면: 폴더
- 하신 말: "폴더 페이지의 카드는 2열 → 1열로 바꿔야 해요."
- 상황: PC 별 카드가 두 개씩 나란히 있었다. 한 줄에 하나씩 쌓았다.
- 뜻: 카드를 몇 줄로 늘어놓는지가 열 수. 하나씩 쌓으면 스택 목록.
- 전하는 말: "카드는 1열 스택으로."
- 이어서: 단일 열 레이아웃

### 아코디언 (accordion) · 펼침 행 (expandable row)
- 날짜: 2026-09-29 · 화면: PC (폴더 합침)
- 하신 말: "폴더랑 PC 합치는 게 좋을 거 같아요. PC 클릭하면 리스트가 동적으로 내려오면서, 해당 PC 에 연결된 폴더 리스트를 보여 주게요."
- 상황: 폴더 메뉴를 없애고 PC 목록의 각 행을 누르면 그 PC 의 폴더가 아래로 펼쳐지게 했다. 행 앞의 ▸/▾ 가 펼침 표시(디스클로저). 모바일도 같은 방식.
- 뜻: 머리를 누르면 아래 내용이 접혔다 펼쳐지는 목록. 표의 한 행이 펼쳐지면 펼침 행.
- 전하는 말: "PC 목록을 아코디언으로, 행을 누르면 폴더 목록이 펼쳐지게 해 주세요."
- 이어서: 디스클로저 (disclosure) · 점진적 공개

### 필수 인자 (required argument) · 선택 인자 (optional argument) · 옵션 (flag)
- 날짜: 2026-09-29 · 화면: 명령행 (C-01, 데모 에이전트 패널)
- 하신 말: "ctx-hub folder add \"신규 입사 지원\" 명령어에 구체적인 디렉토리 지정이 없네요."
- 상황: 경로를 빼면 폴더 선택 창을 여는 식이었다. 명령행은 명령만 보고 결과를 알 수 있어야 하므로 경로를 필수로 바꿨다. 빠지면 예시와 함께 오류를 낸다. 도움말 표기는 `ctx-hub folder add "<프로젝트>" <경로> [--replace]`.
- 뜻: 꼭 써야 하는 값이 필수 인자(`<경로>`), 빼도 되는 값이 선택 인자(`[경로]`), `--replace` 처럼 켜고 끄는 스위치가 옵션. 도움말에서 `< >` 는 필수, `[ ]` 는 선택을 뜻한다.
- 전하는 말: "folder add 의 경로는 필수 인자로 해 주세요."
- 이어서: 사용법 표기 (usage syntax)

### 페이지네이션 (pagination)
- 날짜: 2026-09-29 · 화면: 자료 (W-02)
- 하신 말: "자료 수를 늘려서 w에서는 자료 페이지 넘기기"
- 상황: 자료가 12건이라 한 화면에 다 보였다. 48건으로 늘리고 10건씩 끊어 [‹ 이전] 1 2 3 4 5 [다음 ›] 로 넘기게 했다. 현재 쪽은 검정 채움. 검색이나 필터를 바꾸면 1쪽으로 돌아간다.
- 뜻: 긴 목록을 일정한 수로 잘라 쪽 번호로 넘겨 보는 방식. 몇 번째 쪽에 무엇이 있었는지 다시 찾아가기 쉽다.
- 전하는 말: "자료 표는 10건씩 페이지네이션으로 나눠 주세요. 필터를 바꾸면 1쪽으로."
- 이어서: 페이지 크기 (page size)

### 무한 스크롤 (infinite scroll) · 지연 로딩 (lazy loading)
- 날짜: 2026-09-29 · 화면: 자료 (M-02 · M-02b)
- 하신 말: "m에서는 스크롤 하면 5개씩 로딩"
- 상황: 휴대폰에서는 쪽 번호를 누르기 불편하다. 처음에 5건을 보이고, 목록 끝에 닿으면 5건을 더 붙였다. Figma 에 끝까지 내린 상태(M-02b)를 따로 그렸다.
- 뜻: 쪽을 넘기지 않고 내리는 대로 다음 묶음을 불러와 이어 붙이는 방식. 필요할 때 불러온다는 점에서 지연 로딩이라고도 한다. 끝에 닿았는지는 마지막 카드가 보이는지로 안다.
- 전하는 말: "모바일 자료 목록은 무한 스크롤로, 5건씩 불러와 주세요."
- 이어서: 더 보기 버튼 (load more)

### 로딩 표시 (loading indicator) · 스피너 (spinner)
- 날짜: 2026-09-29 · 화면: 자료 (M-02b)
- 하신 말: "스크롤 하면 5개씩 로딩"
- 상황: 다음 5건을 받는 동안 목록 끝에 도는 원과 "불러오는 중" 을 보였다. 없으면 끝에 닿아도 아무 일이 없는 것처럼 보인다.
- 뜻: 기다리는 중이라는 것을 알리는 표시. 도는 원이 스피너, 채워지는 막대가 진행 막대다. 전달중 64% 막대가 진행 막대다.
- 전하는 말: "더 불러오는 동안 목록 끝에 스피너를 보여 주세요."
- 이어서: 스켈레톤 (skeleton)

## 빨리 찾기

| 사용자가 이렇게 말하면 | 용어 |
|---|---|
| 설명하는 글이 너무 많다 | 마이크로카피 과다, 도움말 텍스트 |
| 최소한의 글로 알아보게 | 자명한 UI, 점진적 공개 |
| 별도 페이지로 꺼내서 | 전용 화면 분리, 정보 구조(IA) |
| "정말 __ 하시겠습니까?" 창 | 확인 대화상자, 파괴적 동작 확인 |
| 열이 두 개가 되지 않게 | 단일 열 레이아웃 |
| 폼과 표를 탭 형식으로 | 탭, 밑줄 탭 |
| 카드 2열 → 1열 | 그리드 열 수, 스택 목록 |
| 아이콘은 왼쪽, 제목은 오른쪽 한 줄로 | 가로 배치 헤더, 리딩 아이콘, 미디어 오브젝트 |
| 제목에 실제 이름 대신 '파일' 로 | 대상 유형으로 부르기 |
| 아이콘을 제목 두 줄 크기로 | 아이콘 크기를 행간에 맞춤 |
| 제목을 아이콘과 가운데 정렬 | 세로 가운데 정렬 |
| x 표시는 원래 위치인 우측 상단에 | 닫기 버튼 고정, 절대 위치 |
| 내용이 붕 뜨는 느낌 | 정렬선, 근접성, 시각적 그룹 |
| 버튼 줄을 따로 나눈 띠 | 푸터 띠 |
| 누르면 리스트가 아래로 내려오게 | 아코디언, 펼침 행 |
| 가로 길이가 어중간, 좌우로 꽉 채우게 | 채움 너비 (fill container) |
| 명령에 값(디렉토리) 지정이 없다 | 필수 인자, 사용법 표기 `< >` `[ ]` |
| 페이지 넘기기 | 페이지네이션 |
| 스크롤하면 더 불러오기 | 무한 스크롤, 지연 로딩 |
| 불러오는 중 도는 표시 | 로딩 표시, 스피너 |
| 같은 말을 두 번 하는 안내 | 마이크로카피 과다 (중복 안내) |
