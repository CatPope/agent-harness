```
## 1. 지금 상태
   한 문단. 목표가 무엇이고 어디까지 왔는가. 성공했는지 실패했는지를 첫 문장에.
## 2. 한 일과 산출물
   결과물 단위로. 파일 경로를 문자열 그대로. 만든 것과 고친 것을 구분한다.
## 3. 시도한 것과 결과
   표. 열은 시도 · 바꾼 것 하나 · 결과(수치) · 판정. 실패한 시도도 전부 넣는다.
   "같은 것을 다시 시험하지 않으려는 목록"이므로 빠뜨리면 압축 뒤에 반복한다.
## 4. 내린 결정과 근거
   네가 스스로 정한 것과 지시서가 정해 준 것을 나눠 적는다.
## 5. 남은 일과 다음 첫 행동
   미완 항목. 압축 뒤 가장 먼저 할 한 가지를 명시한다.
## 6. 지켜야 할 제약 (원문 그대로)
   지시서의 금지사항, 백업 규칙, 예산(GUI 횟수 등) 잔량을 **줄여 쓰지 말고 원문대로** 옮긴다.
   압축되면 제약이 가장 먼저 흐려진다.
## 7. 다시 열어 볼 파일
   근거가 되는 로그·보고서·스크립트의 경로 목록.
```

## 하지 않는 것

- **이 턴에서 코드·씬·자산·기존 문서를 고치지 마라.** `작업내역.md` 도 고치지 마라(다음 턴에서 한다).
- 새로 만드는 파일은 **위 경로의 하나뿐**이다. 다른 파일을 만들지 마라.
- 새 시험이나 GUI 실행을 하지 마라. **기록만 한다.**
- 확인하지 않은 것을 확인한 것처럼 쓰지 마라. 추정은 "추정"이라고 적는다.
